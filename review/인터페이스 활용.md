<h1>인터페이스 활용</h1>

<h2>인터페이스 확장</h2>
: 공통분모가 되는 속성을 부모 인터페이스로 두고 자식 인터페이스에서 세부 속성 추가
ex)
interface Animal {
    name: string;
  }

interface Dog extends Animal {
breed: string;
}
☞ extends를 이용해 Animal 상속

const myDog: Dog = {
name: "Charlie",
breed: "Beagle",
};
☞ 해당 'Dog' 타입을 갖는 개체는 'Animal'의 속성인 'name'과 'Dog'의 속성인 'breed'를 모두 갖고 있음.

- 다중 상속 가능
  : 다양한 능력을 가진 개체를 만들 때 자주 사용. (mixin 스타일)

interface CanRun{
run(): void;
}

interface CanBark {
bark(): void;
}

interface Dog extends CanRun, CanBark {}

☞ Dog는 그 자체로는 따로 속성을 갖지 않음.

const myDog: Dog = {
run() {
console.log("Running!");
},
bark() {
console.log("Woof"!);
},
};

- 다중 상속 주의할 점
  ex)
  interface interfaceA {
  // value: string;
  ☞ 속성의 이름이 같은데 하나는 문자열 타입, 하나는 숫자 타입이기 때문에 함께 상속을 하려 하면 충돌로 컴파일 오류 발생
  valueA: string;
  ☞ 그렇기 때문에 'value'가 아닌 'valueA'로 속성명 변경.
  value: string | number;
  }

interface InterfaceB {
// value: number;
☞ 위와 동일
valueB: number;
value: string | number;
}

interface InterfaceC extends InterfaceA, InterfaceB {}

☞ 속성명이 꼭 같아야만 한다면 위처럼 타입 유니언을 사용.

- 중첩된 인터페이스
  : 한 인터페이스가 다른 인터페이스를 포함.

ex)

interface ContactInfo {
phone: string;
email: string;
}

interface Employee {
name: string;
contact: ContactInfo;
}
☞ 위처럼 한 인터페이스에 다른 인터페이스의 속성 적용 가능.

const dev: Employee = {
name: "Jane",
contact: {
phone: "010-1234-5678",
email: "Hane@example.com",
},
};
