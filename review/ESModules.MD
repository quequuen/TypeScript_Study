<h2> ES Modules </h2>

- ES Modules 설정 방법

1. package.json 내
   {
   "type" : "module"
   }

2. 모듈로 사용할 파일 확장자 .mjs

☞ 최신 버전 Node.js는 이렇게 안해도 동작하지만 언제나 최신 버전을 쓸 수는 없기 때문에 위 두개 중 하나를 사용하는 것이 좋음.

- module 기본 사용
  math.js 파일 내 예시

☞ 각각의 선언 및 할당되는 곳 앞에 export 키워드

app.js 내 예시


- 각 모듈 문서에는 대표하는 값이 있는 경우 존재(함수, 객체 등)
  해당 상황에는 default 키워드로 지정

  ☞ 모듈의 대표값(이름은 자유자재)은 중괄호 밖에, 다른 값들은 각각의 이름 그대로 중괄호 안에 넣으면 됨.
  ☞ 하나의 값에만 default 사용 가능

  - 서로 다른 모듈에서 같은 이름의 값들이 내보내어지는 경우

  1. \* 별표 사용으로 각각 개체 지정

2. 같은 이름의 값을 as 키워드를 사용해 다른 이름으로 지정

- 캐싱 관련 예제

☞ 다른 파일에서 임포트해 실행을 해도 캐싱이 되어 결과가

1. 0
2. 1
3. 1
4. 2
   가 됨

☞ 같은 모듈을 임포트하더라도 캐싱되지 않게 하려면 실제적으로 해당 모듈을 사용하는 경로에 서로 다른 쿼리 스트링을 붙여주면 됨


☞ 경로 문자열이 달라지면 새로운 모듈로 인식되어 결과가

1. 0
2. 1
3. 0
4. 1
   가 됨
