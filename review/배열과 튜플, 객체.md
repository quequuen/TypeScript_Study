<h1>배열</h1>

- 배열 구조

1. 1차원 배열<br>
     ex)<br>
     let numbers: number[] = [1,2,3,4,5,6];<br>
<br>
  let fruits: Array<string> = ["Apple", "Banana", "Orange"];<br>
<br>
  let scores: number[] = [];<br>
  scores.push(95);<br>
  scores.push(88);<br>
<br>
  2. 2차원 배열<br>
     ex)<br>
     let matrix: number[][] = [<br>
     [1,2,3],<br>
     [4,5,6],<br>
     [7,8,9],<br>
     ]<br>
<br>
  3. 3차원 배열<br>
     ex)<br>
     let cube: number[][][] = [<br>
     [[1,2],[3,4]],<br>
     [[5,6],[7,8]],<br>
     ];<br>
<br>
- 배열 예시<br>
<br>
  const names: string[] = ["Alice", "Bob", "Charlie", "David", "Boy"];<br>
<br>
  1. map<br>
     ex)<br>
     const nameLengths: number[] = names.map((name)=> name.length);<br>
<br>
  2. filter<br>
     ex)<br>
     const longNames: string[] = names.filter((name)=> name.length > 4);<br>
<br>
  3. find<br>
     ex)<br>
     const foundName: string | undefined = names.find((name)=>name.startsWith("B"));<br><br>
     ☞ filter가 아닌 find이기 때문에 오류가 나지 않고 먼저 나오는 Bob가 출력<br><br>
<br>
- 배열 읽기 전용<br>
<br>
  1. 일반 배열<br>
     const originalArray: number[] =[1,2,3,4,5];<br>
     originalArray[0] = 10;<br><br>
     ☞ const는 재할당을 막음.<br><br>
     originalArray = [10, 20, 30];<br><br>
     ☞ 이건 재할당이라 안됨<br><br>
     originalArray[0] = 10;<br><br>
     ☞ 이건 재할당이 아닌 내용 변경이라 가능<br><br>
<br>
  2. 읽기 전용 배열<br>
     const readOnlyNumbers: ReadonlyArray<number> = originalArray;<br><br>
     ☞ 제네릭 표현으로 가능.<br><br>
     const readOnlyScores: readonly number[] = [90,85,95];<br><br>
     ☞ 위 둘은 재할당도 내용 변경도 안됨.<br><br>
<br>
  3. 읽기 전용인 배열 사용하는 법(스프레드 연산자 사용)<br>
     const newArray = [...readOnlyNumbers, 6]; //[1,2,3,4,5,6]<br>
     newArray[0] = 0;<br>
     newArray.push(7);<br>
<br>
<h1>튜플</h1>

- 튜플 구조<br>
  let person: [string, number] = ["John", 30];<br><br>
  ☞ 튜플은 배열처럼 생겼지만, 각 요소의 타입과 순서가 정해져 있고 이를 어기면 컴파일 오류가 발생함.<br><br>
<br>
- 튜플을 이용한 구조분해할당<br>
  const [firstName, age] = person;<br>
<br>
- 선택적 요소 포함 가능<br>
  ex)<br>
  type OptionalTuple = [string, number, boolean?];<br><br>
  ☞ 물음표를 붙일 시, 선택적 요소로 인지<br><br>
  const complete: OptionalTuple = ["Jane", 25, true];<br><br>
  ☞ 마지막 요소가 들어갈 수도 있고<br><br>
  const partial: OptionalTuple = ["Mike", 40];<br><br>
  ☞ 마지막 요소가 들어가지 않을 수도 있음.<br><br>
<br>
- 튜플을 함수 반환값으로 사용하는 예제<br>
  function getUserInfo(): [string, number, boolean]{<br>
  return ["alex_dev", 28, false];<br>
  }<br>
<br>
  const [username, userAgem, isAdmin] = getUserInfo();<br><br>
  ☞ 리턴값 구조 분해 할당<br><br>
<br>
- 타입 추론에 있어 배열과 튜플의 차이<br>
<br>
  const inferredArray = [1, "Hello"];<br>
  //inferredArray: (string | number)[]<br>
<br>
  const inferredTuple = [1, "Hello"] as const;<br>
  //inferredTuple: readonly [1, 'Hello']<br><br>
  ☞ 각 값이 상수가 되어버려서 이 값들 외에는 다른 값들이 들어올 수가 없음<br><br>
  ☞ 실무에서 필요시 특정 데이터 묶음의 값 제약이 가능함.<br>
<br>
  // inferredTuple[0] = 2; //오류<br>
  // inferredTuple[1] = "world"; //오류<br>
<br>
<h1>객체</h1>

- 객체 구조<br>
  ex)<br>
  let person: {name: string; age: number} = {name: "John", age: 25};<br>
<br>
  const wrongPerson1: { name: string; age: number } = {<br>
  name: "John",<br>
  age: "25",<br>
  };<br><br>
  ☞ age의 타입이 숫자인 관계로 "25"와는 타입이 맞지 않아 오류<br><br>
<br>
  const wrongPerson2: { name: string; age: number } = { name: "Mark" };<br><br>
  ☞ name과 age가 와야 하는데 name만 와서 오류<br><br>
<br>
  const wrongPerson3: {name: string; age: number} = {name: "John", age: 25, married: true,}<br><br>
  ☞ 타입에서 정의 되지 않은 속성을 넣어 오류<br><br>
<br>
- 객체 사용 예시<br>
  interface User {<br>
  id: number;<br>
  username: string;<br>
  isAdmin: boolean;<br>
  }<br>
<br>
  1. 옳은 예시<br>
     ex)<br>
     const adminUser: User = {<br>
     id: 0,<br>
     username: "admin",<br>
     isAdmin: true,<br>
     };<br>
<br>
  2. 틀린 예시<br>
     ex)<br>
     const user1: User1 = {<br>
     id: 1, username: "admin",<br>
     }<br><br>
     ☞ User1이란 타입을 정의헤놓은 객체가 없을 뿐더러 isAdmin이 들어가지 않아 구조가 일치하지 않음<br>
<br>
  const user2: User = {<br>
  id: "2",<br>
  username: "admin",<br>
  isAdmin: false,<br>
  }<br><br>
  ☞ id 타입이 맞지 않음<br>
