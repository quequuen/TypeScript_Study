<h1>배열</h1>

- 배열 구조

  1. 1차원 배열
     ex)
     let numbers: number[] = [1,2,3,4,5,6];

  let fruits: Array<string> = ["Apple", "Banana", "Orange"];

  let scores: number[] = [];
  scores.push(95);
  scores.push(88);

  2. 2차원 배열
     ex)
     let matrix: number[][] = [
     [1,2,3],
     [4,5,6],
     [7,8,9],
     ]

  3. 3차원 배열
     ex)
     let cube: number[][][] = [
     [[1,2],[3,4]],
     [[5,6],[7,8]],
     ];

- 배열 예시

  const names: string[] = ["Alice", "Bob", "Charlie", "David", "Boy"];

  1. map
     ex)
     const nameLengths: number[] = names.map((name)=> name.length);

  2. filter
     ex)
     const longNames: string[] = names.filter((name)=> name.length > 4);

  3. find
     ex)
     const foundName: string | undefined = names.find((name)=>name.startsWith("B"));
     ☞ filter가 아닌 find이기 때문에 오류가 나지 않고 먼저 나오는 Bob가 출력

- 배열 읽기 전용

  1. 일반 배열
     const originalArray: number[] =[1,2,3,4,5];
     originalArray[0] = 10;
     ☞ const는 재할당을 막음.
     originalArray = [10, 20, 30];
     ☞ 이건 재할당이라 안됨
     originalArray[0] = 10;
     ☞ 이건 재할당이 아닌 내용 변경이라 가능

  2. 읽기 전용 배열
     const readOnlyNumbers: ReadonlyArray<number> = originalArray;
     ☞ 제네릭 표현으로 가능.
     const readOnlyScores: readonly number[] = [90,85,95];
     ☞ 위 둘은 재할당도 내용 변경도 안됨.

  3. 읽기 전용인 배열 사용하는 법(스프레드 연산자 사용)
     const newArray = [...readOnlyNumbers, 6]; //[1,2,3,4,5,6]
     newArray[0] = 0;
     newArray.push(7);

<h1>튜플</h1>

- 튜플 구조
  let person: [string, number] = ["John", 30];
  ☞ 튜플은 배열처럼 생겼지만, 각 요소의 타입과 순서가 정해져 있고 이를 어기면 컴파일 오류가 발생함.

- 튜플을 이용한 구조분해할당
  const [firstName, age] = person;

- 선택적 요소 포함 가능
  ex)
  type OptionalTuple = [string, number, boolean?];
  ☞ 물음표를 붙일 시, 선택적 요소로 인지
  const complete: OptionalTuple = ["Jane", 25, true];
  ☞ 마지막 요소가 들어갈 수도 있고
  const partial: OptionalTuple = ["Mike", 40];
  ☞ 마지막 요소가 들어가지 않을 수도 있음.

- 튜플을 함수 반환값으로 사용하는 예제
  function getUserInfo(): [string, number, boolean]{
  return ["alex_dev", 28, false];
  }

  const [username, userAgem, isAdmin] = getUserInfo();
  ☞ 리턴값 구조 분해 할당

- 타입 추론에 있어 배열과 튜플의 차이

  const inferredArray = [1, "Hello"];
  //inferredArray: (string | number)[]

  const inferredTuple = [1, "Hello"] as const;
  //inferredTuple: readonly [1, 'Hello']
  ☞ 각 값이 상수가 되어버려서 이 값들 외에는 다른 값들이 들어올 수가 없음
  ☞ 실무에서 필요시 특정 데이터 묶음의 값 제약이 가능함.

  // inferredTuple[0] = 2; //오류
  // inferredTuple[1] = "world"; //오류

<h1>객체</h1>

- 객체 구조
  ex)
  let person: {name: string; age: number} = {name: "John", age: 25};

  const wrongPerson1: { name: string; age: number } = {
  name: "John",
  age: "25",
  };
  ☞ age의 타입이 숫자인 관계로 "25"와는 타입이 맞지 않아 오류

  const wrongPerson2: { name: string; age: number } = { name: "Mark" };
  ☞ name과 age가 와야 하는데 name만 와서 오류

  const wrongPerson3: {name: string; age: number} = {name: "John", age: 25, married: true,}
  ☞ 타입에서 정의 되지 않은 속성을 넣어 오류

- 객체 사용 예시
  interface User {
  id: number;
  username: string;
  isAdmin: boolean;
  }

  1. 옳은 예시
     ex)
     const adminUser: User = {
     id: 0,
     username: "admin",
     isAdmin: true,
     };

  2. 틀린 예시
     ex)
     const user1: User1 = {
     id: 1, username: "admin",
     }
     ☞ User1이란 타입을 정의헤놓은 객체가 없을 뿐더러 isAdmin이 들어가지 않아 구조가 일치하지 않음

  const user2: User = {
  id: "2",
  username: "admin",
  isAdmin: false,
  }
  ☞ id 타입이 맞지 않음
