##고급 타입들(심화)

- 맵드 타입과 인덱스 시그니처의 활용
  type User = {
  id: number;
  name: string;
  email: string;
  };

  type OptionalUser = {
  [K in keyof User]?: User[K];
  ☞ 물음표가 붙으면 각각이 선택적 속성이 됨.
  };

  const user1: OptionalUser = {
  name: "Alice",
  };

  const user2: OptionalUser = {
  id: 1,
  email: "bob@example.com",
  };

  ☞ 기존의 객체 타입으로부터 보다 유연한 형태의 타입들을 만들어낼 수 있음.
