## 고급 타입들 (심화)

TypeScript의 고급 타입(심화)은  
**기존 타입을 변형·조합·검증**하여  
더 엄격하고 안전한 타입 시스템을 설계할 수 있도록 돕는다.

---

### 맵드 타입과 인덱스 시그니처

기존 객체 타입을 기반으로  
모든 속성을 **선택적(optional)** 혹은 **readonly**로 변환할 수 있다.


☞ 기존 타입을 재사용하면서 더 유연한 타입을 만들 수 있음.

---

### Readonly 맵드 타입

모든 속성을 **읽기 전용**으로 만들어  
객체 변경을 방지한다.


☞ API 응답, 설정 객체 등에 유용.

---

### 템플릿 리터럴 타입

문자열 리터럴 타입을 조합하여  
**패턴 기반 문자열 타입**을 생성한다.


☞ 문자열 규칙을 타입 레벨에서 강제 가능.

---

### 다중 리터럴 타입 조합

여러 리터럴 타입을 결합해  
경우의 수를 자동 생성한다.


☞ 상태값, 옵션 키 설계에 매우 유용.

---

### instanceof 기반 타입 가드

클래스 기반 객체를 안전하게 구분한다.


---

### 사용자 정의 타입 가드

복잡한 타입 판별 로직을 함수로 분리한다.


☞ 여러 곳에서 반복되는 타입 판별에 매우 유용.

---

### Type Assertion (타입 단언)

TypeScript에게 **“내가 타입을 보장한다”**고 알려주는 방법.


☞ 잘못 사용하면 런타임 오류 발생 가능.

---

### Non-null 단언 연산자 (`!`)

값이 `null | undefined`가 아님을 단언한다.


☞ 실제로 `undefined`면 런타임 오류 발생.

---

### 정리

- 고급 타입은 **강력하지만 위험할 수 있음**
- 타입 가드 → 가장 안전
- 타입 단언 → 최후의 수단
- 템플릿 리터럴 / 맵드 타입 → 설계 단계에서 특히 강력
