##내장 제네릭 타입과 유틸리티 타입

<h2>내장 제네릭 타입</h2>
: 타입스크립트에서 기본으로 제공하는 제네릭 타입(배열, 프로미스 등)
    +)원본 배열의 불변성을 유지할 필요가 있는 경우 ReadonlyArray<T> 타입을 사용
    Map(키와 값을 갖는 요소)/Set(중복되지 않는 것들의 집합) 등도 제네릭 타입을 지원

<h3>WeakMap과 WeakSet</h3>

const obj1 = {id: a};
const obj2 = {id: b};
☞ WeakMap은 키로 객체만 허용(obj1, 2는 WeakMap의 키용 객체)

const weakMap: WeakMap<object, string> = new WeakMap();
weakMap.set(obj1, "Obj1");

console.log(weakMap.get(obj1));

const objA = {name: "Alice"};
const objB = {name: "Bob"};

const weakSet: WeakSet<object> = new WeakSet();
weakSet.add(objA);
☞ WeakSet은 객체만 요소로 허용

console.log(weakSet.has(objA)); ☞ true
console.log(weakSet.has(objB)); ☞ false
☞ 객체들이 가비지 컬렉션의 대상이 될 수 있도록 허용
☞ 즉, 더 이상 참조되지 않는 객체들은 메모리에서 자동으로 해제될 수 있음. (누수 방지)

<h3>Utility Types</h3>

☞ TypeScript에서 제공하는 유틸리티 타입들은 기존 타입을 변형하거나 조작하는 데 사용되는 내장 제네릭 타입들.

- Partial<T>
  ☞ 주어진 객체 타입의 모든 속성은 '선택적 속성으로 만들어주는 데 사용.'

interface Product{
id: number;
name: string;
}

const partialProduct: Partial<Product> ={
name: "Cup",
};

☞ 제네릭으로 전달한 결과를 타입으로 사용함.
☞ 그 결과로 만들어진 타입은 'Product'의 모든 속성을 선택적으로 만듦.

- Required<T>
  ☞ Partial과 정반대 기능
  ☞ 전달된 객체 타입의 속성들을 모두 필수 속성으로 갖는 타입.

interface UserProfile{
name: string;
age: number;
}

const completeProfile: Required<UserProfile> = {
name: "Bob",
age: 25,
}
☞ 'UserProfile'의 모든 속성을 필수 속성으로 만듦.

//const completeProfile2: Required<UserProfile> = {
//name: "Bob",
//}
☞ 필수 속성인 age가 없어서 오류

- Readonly<T>
  ☞ 읽기 전용 속성

interface Settings {
theme: string;
darkMode: boolean;
}

const config: Readonly<Settings> = {
theme: "light",
darkMode: true,
};

// config.theme = "dark";

☞ Readonly로 인해 수정 불가

- Pick<T>

  price: number;

const productPreview1: Pick<Product, "id" | "name"> = {
